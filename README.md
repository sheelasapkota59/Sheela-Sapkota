###  Research & Projects

**Kinship Verification (M.S. Thesis, in progress)**
Kinship verification from facial images using margin-based deep face recognition losses. Instead of the whole face, I compare individual facial parts (eyes, eyebrows, nose, mouth, forehead, ears).
- Backbones: ResNet-100 and InceptionResNetV1
- Losses: ArcFace vs. ElasticFace, inside a Siamese triplet network
- Part-attention to weight each facial part, plus a DCT frequency stream for fine detail
- Grad-CAM to show which features drive each decision
- Dataset: Family101 (father–son, father–daughter, mother–son, mother–daughter)
